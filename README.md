# React Native PDF Reusables

Source-owned, customizable PDF components for React Native and Expo.

## Commands

    pnpm install
    pnpm build
    pnpm lint
    pnpm typecheck

## Components

- `Document` and `Page`
- `Stack`, `Heading`, `Text`, `Image`, `Divider`, and `Link`
- Typed printable styles
- HTML serialization and Expo PDF generation
