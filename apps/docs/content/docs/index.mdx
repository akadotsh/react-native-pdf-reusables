---

React Native PDF Reusables is a collection of printable React components for
building PDFs in React Native and Expo apps.

The components produce a document tree that can be serialized to HTML and
rendered to PDF. They do not render ordinary React Native views.

## Distribution direction

The project is moving toward a source registry: users will copy selected
components into their own app through a CLI, similar to shadcn/ui and React
Native Reusables.
