All components return a printable document tree. They are interpreted by
`renderToHtml` and `renderToPdf`; they do not render React Native views.

Each component includes a package-manager command you can copy. The commands
copy the component source and its shared dependencies into your project. See
[Installation](/docs/installation) for output paths and CLI options.

## Document structure

### Document

<InstallCommand name="document" />

The root of a printable tree. `title` becomes the generated HTML document title.

| Prop | Type | Purpose |
| --- | --- | --- |
| `children` | `ReactNode` | Pages and providers in the document. |
| `title` | `string` | Optional PDF document title. |

### Page

<InstallCommand name="page" />

Creates a physical page section with an explicit page break after it.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `'A4' \| 'Letter'` | `'A4'` |
| `style` | `PdfStyleProp` | — |
| `children` | `ReactNode` | — |

### Stack

<InstallCommand name="stack" />

Arranges children vertically. Use `gap` for predictable spacing rather than
adding margins to every child.

| Prop | Type | Purpose |
| --- | --- | --- |
| `gap` | `number` | Vertical gap in PDF points/pixels. |
| `style` | `PdfStyleProp` | Overrides or extends the stack style. |
| `children` | `ReactNode` | Stack content. |

### ThemeProvider

<InstallCommand name="theme-provider" />

Makes color, font, and spacing tokens available to style functions below it.
It does not emit an extra HTML element.

| Prop | Type | Purpose |
| --- | --- | --- |
| `tokens` | `ThemeTokens` | Partial color, font, and spacing tokens. |
| `children` | `ReactNode` | The themed document subtree. |

```tsx
<Document title="Invoice 1042">
  <ThemeProvider tokens={{ colors: { accent: '#2563eb' } }}>
    <Page size="A4" style={{ padding: 40 }}>
      <Stack gap={16}>
        <Heading>Invoice</Heading>
        <Text>Prepared on this device.</Text>
      </Stack>
    </Page>
  </ThemeProvider>
</Document>
```

## Typography and media

### Heading

<InstallCommand name="heading" />

Creates an `h1`, `h2`, or `h3` in generated output. `level` defaults to `1`.

### Text

<InstallCommand name="text" />

The inline text primitive. It accepts printable children and an optional
`PdfStyleProp`.

### Link

<InstallCommand name="link" />

Creates a clickable link. Pass the destination through the required `href`
prop and its label through `children`.

### Image

<InstallCommand name="image" />

Embeds an image from a URI or data URI. `src` is required; `alt` and `style`
are optional. For device-local files, confirm the URI is readable by the print
renderer before generating the PDF.

### Divider

<InstallCommand name="divider" />

Creates a horizontal rule. Use `style` to control its color, thickness, and
spacing.

```tsx
<Stack gap={8}>
  <Heading level={2}>Payment details</Heading>
  <Text style={{ color: '#475569' }}>Due within 30 days.</Text>
  <Link href="https://example.com/invoices/1042">Open invoice</Link>
  <Divider style={{ borderColor: '#e2e8f0' }} />
  <Image src={logoDataUri} alt="Company logo" style={{ width: 96 }} />
</Stack>
```

## Page behavior

### PageHeader

<InstallCommand name="page-header" />

Creates a semantic header region. Its final repetition and positioning depend
on the platform print engine, so validate it on both iOS and Android.

### PageFooter

<InstallCommand name="page-footer" />

Creates a semantic footer region. Its final repetition and positioning depend
on the platform print engine, so validate it on both iOS and Android.

### PageBreak

<InstallCommand name="page-break" />

Forces all following content onto a new printed page. It has no props.

### KeepTogether

<InstallCommand name="keep-together" />

Applies print rules that ask the renderer not to split its children across
pages. Very tall content can still be split when it cannot fit on one page.

### Watermark

<InstallCommand name="watermark" />

Places content at the center of printed output with fixed positioning, reduced
opacity, and a default diagonal rotation. Override those values through `style`.

```tsx
<Page>
  <PageHeader><Text>Quarterly report</Text></PageHeader>
  <Watermark><Heading>Draft</Heading></Watermark>
  <KeepTogether>
    <Heading level={2}>Summary</Heading>
    <Text>This heading and paragraph should remain together.</Text>
  </KeepTogether>
  <PageBreak />
  <PageFooter><Text>Confidential</Text></PageFooter>
</Page>
```

## Structured data

### KeyValueList

<InstallCommand name="key-value-list" />

Renders label/value pairs with labels on the left and values aligned on the
right. Pass an `items` array containing `{ label, value }` objects.

### DataTable

<InstallCommand name="data-table" />

Builds a typed table from `rows` and column definitions. Each column provides a
`header` and a `render(row, index)` function.

| Prop | Type | Purpose |
| --- | --- | --- |
| `rows` | `readonly Row[]` | Data rendered into table rows. |
| `columns` | `readonly DataTableColumn<Row>[]` | Header and cell renderers. |
| `repeatHeader` | `boolean` | Repeats the header after page breaks by default. |
| `headerStyle` | `PdfStyleProp` | Shared header-cell style. |
| `cellStyle` | `PdfStyleProp` | Shared body-cell style. |
| `style` | `PdfStyleProp` | Table-level style. |

### Totals

<InstallCommand name="totals" />

Renders summary label/value pairs as one keep-together block. Its `items` use
the same shape as `KeyValueList`.

### Signature

<InstallCommand name="signature" />

Keeps signature content, a rule, and its optional `label` together. Use
`children` for the signed name or image.

```tsx
<Stack gap={20}>
  <KeyValueList items={[
    { label: 'Invoice', value: 'INV-1042' },
    { label: 'Customer', value: 'Acme & Partners' },
  ]} />

  <DataTable
    rows={lines}
    columns={[
      { header: 'Item', render: (line) => line.name },
      { header: 'Amount', render: (line) => line.amount },
    ]}
  />

  <Totals items={[{ label: 'Total', value: 'INR 1,180' }]} />
  <Signature label="Authorized signature">Akash Prasad</Signature>
</Stack>
```
