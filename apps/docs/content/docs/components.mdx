title: Components
description: Printable building blocks currently available in the project.
---

## Document structure

- `Document`, `Page`, and `Stack`
- `PageHeader`, `PageFooter`, `PageBreak`, and `KeepTogether`
- `ThemeProvider` and `Watermark`

## Content

- `Heading`, `Text`, `Image`, `Link`, and `Divider`
- `KeyValueList`, `DataTable`, `Totals`, and `Signature`

These components describe printable output. Use the native playground in this
repository to validate generated PDFs on iOS and Android.
