The installation model is source-owned: the CLI copies component files into
your project instead of adding a runtime component library.

## Add a component

<InstallCommand name="text" />

Add multiple components in one command:

<InstallCommand name="document page stack text" />

The CLI also copies shared files such as `style.ts` and component dependencies.
Running the same command again leaves unchanged files alone.

## Add the renderer

The renderer uses the complete primitive set, so this command installs all
components together with `render-to-html.ts`, `render-to-pdf.ts`, and font and
style support:

<InstallCommand name="renderer" />

Install `expo-print` when using `renderToPdf`:

```bash
npx expo install expo-print
```

`renderToHtml` does not require Expo Print.

## Output directory

Projects with a `src` directory receive files in `src/components/pdf`.
Otherwise, the CLI uses `components/pdf`. Override the destination from the
project root when needed:

```bash
npx react-native-pdf-reusables@latest add text --path src/pdf
```

Existing changed files are never replaced automatically. Review your local
changes before explicitly allowing replacement:

```bash
npx react-native-pdf-reusables@latest add text --overwrite
```

## Try the components today

Clone this repository, install the workspace, and start the native playground:

```bash
pnpm install
pnpm --filter pdf-reusables-playground start
```

The playground generates PDFs on-device, so page breaks, headers, local images,
and other native behavior can be validated on iOS or Android.

See the [Playground guide](/docs/playground) for the complete device workflow
and validation checklist.
